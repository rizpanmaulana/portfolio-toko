PORTFOLIO-TOKO

Website toko online sederhana yang dibangun menggunakan HTML, CSS, dan JavaScript.

Demo Live

🔗 https://gregarious-rolypoly-f5a385.netlify.app/

Fitur

- Katalog produk dengan gambar dan harga
- Pencarian produk
- Filter berdasarkan kategori
- Pengurutan harga
- Keranjang belanja dengan fitur tambah, kurang, dan hapus produk
- Perhitungan jumlah barang dan total belanja
- Penyimpanan keranjang menggunakan LocalStorage
- Batas maksimal 99 unit per produk
- Checkout melalui WhatsApp dengan ringkasan pesanan

Teknologi

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Netlify untuk deployment

Cara Menjalankan

1. Clone atau unduh repository ini.
2. Buka "index.html" melalui browser atau editor yang mendukung preview website.
3. Pastikan folder "gambar/" berada di lokasi yang benar.

Tujuan Project

Project ini dibuat untuk mempraktikkan pengembangan front-end, manipulasi DOM menggunakan JavaScript, pengelolaan keranjang belanja, penyimpanan data browser, dan deployment website statis.

Batasan

Project ini merupakan demo front-end. Belum menggunakan backend, database pesanan terpusat, maupun sistem pembayaran online.
